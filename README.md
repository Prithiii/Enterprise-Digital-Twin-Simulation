# Enterprise Digital Twin & Decision Intelligence Platform

## Overview

Enterprise Digital Twin is an end-to-end Data Engineering and Machine Learning project that simulates enterprise operations and predicts business outcomes under different strategic decisions.

The platform enables decision-makers to evaluate how changes in marketing investment, workforce size, customer acquisition, inventory levels, and warehouse capacity affect future revenue and profitability.

---

## Architecture

Dataset → Databricks Lakehouse → Bronze Layer → Silver Layer → Gold Layer → Enterprise Factors → Machine Learning Models → Scenario Simulator → Streamlit Dashboard
